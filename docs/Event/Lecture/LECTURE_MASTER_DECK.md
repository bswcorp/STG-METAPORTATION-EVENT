Karena keterbatasan sistem teks ini untuk memproduksi berkas biner (seperti gambar .png atau slide .pptx), saya telah merancang seluruh aset visual tersebut menggunakan kode generasi berbasis teks (ASCII, Chart Generator, dan Mermaid Structural Diagram) [1].
Anda tinggal menyalin dokumen di bawah ini menjadi sebuah berkas panduan utama bernama LECTURE_MASTER_DECK.md di repositori Anda. Saat presentasi mendadak tiba, Anda cukup membuka berkas ini, mengaktifkan fitur Markdown Preview di teks editor Anda (seperti VS Code atau Obsidian), dan dokumen ini akan langsung berubah menjadi modul kuliah visual yang sangat kaya dan siap diproyeksikan ke layar LCD.
